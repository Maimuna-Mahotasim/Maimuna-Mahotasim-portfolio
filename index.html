Electronic Voting Machine Database Management System

Database Management / Web-Based Management System — Academic Software Project

Project Overview

An interactive EVM Database Management System simulating the management of voters, candidates, constituencies, voting activity and election results through an administrative dashboard. It provides an admin-oriented interface for logging in and managing every aspect of the election database. This is an academic simulation and is not connected to any real national election system or physical EVM hardware.

Features

  • Admin login with username/password authentication, login validation and logout functionality
  • Admin dashboard showing total voters, total candidates, constituency count, votes cast and election status, plus quick management actions
  • Voter management — registering new voters (name, NID number, date of birth, constituency), a registered voter list, voting status, and eligible-voter voting functionality
  • Candidate management — adding candidates (name, political party, election symbol, constituency) and a nominated candidate list
  • Constituency-based voter management, candidate assignment and polling/location management
  • Voting interface — candidate display by constituency, candidate selection, duplicate-vote prevention and vote-count updates
  • Live result analytics — constituency-wise results, candidate vote counts, vote percentages and current winner, with separate live-result panels for Dhaka-10 and Dhaka-11
  • Activity logs — login/logout activity, voter registration, candidate registration, vote-casting activity and key administrative actions
  • System settings — a visual interface covering security configuration, database connection status and system configuration

Technologies

HTML5CSS3JavaScript Font AwesomeResponsive Web Design DOM ManipulationClient-Side Data Management

Structured as an HTML document with embedded CSS and JavaScript, using Font Awesome for interface icons.

My Contribution

  • End-to-End System Architecture & Development: Independently engineered and built the full-stack web-based EVM Database Management System.
  • Database & Core Logic Design: Modeled and implemented the relational data structure and backend execution logic to manage voters, candidate nominations, constituencies, and activity logs.
  • Dashboard & Analytics Interface: Designed and developed the complete UI using HTML, CSS, and JavaScript — including admin login, voter registration workflow, candidate entry forms, and real-time constituency-wise election analytics.
  • Feature Integration & Deployment: Implemented interactive client-side functionality such as dynamic vote calculation, real-time winner detection per constituency, session activity tracking, and authentication handling.
  • Complete Project Ownership: Led the full lifecycle from initial schema conceptualization to frontend visual layout and full feature implementation.

Challenges & Learning

  • Full-Stack Software Engineering: Hands-on experience bridging front-end interfaces with relational data models and dynamic rendering logic.
  • Data Integrity & State Management: Learned to enforce strict business rules in application logic — single-vote constraints per voter, dynamic percentage tracking, and audit activity logs.
  • UI/UX Design for Administrative Dashboards: Practical skills designing intuitive, accessible control panels that cleanly present analytical data and multi-constituency live results.
  • Problem-Solving & Self-Reliance: Strong independent troubleshooting through full responsibility for debugging, UI layout alignment and functional testing across all modules.
